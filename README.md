# 📁 File Manager - MRIS

A modern, fast and beautiful File Manager app for Android.
Built with **Jetpack Compose**, **Material 3** and **Gemini AI**.

---

### ✨ Features
- Browse Files, Images, Videos, Audio, Documents
- Gallery View with Grid & List Mode
- Built-in Media Player
- Smart Search with Gemini AI
- Dark / Light Mode
- Copy, Move, Rename, Delete, Share

### 📱 How to Get APK
1. Open the **Actions** tab in this repo
2. Select **AI Studio to GitHub APK**
3. Click **Run workflow**
4. Download APK from **Artifacts**

### 🛠️ Built With
- Kotlin
- Jetpack Compose
- Room Database
- Gemini AI
